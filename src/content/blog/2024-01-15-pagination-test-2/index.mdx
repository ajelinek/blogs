# Advanced Pagination Techniques

This is another test post created to ensure we have enough content to demonstrate pagination functionality.

## Pagination Patterns

There are several common pagination patterns:

1. **Numbered pages**: The classic approach with page numbers
2. **Load more**: A button that loads additional content
3. **Infinite scroll**: Content loads automatically as the user scrolls
4. **Cursor-based**: Uses a pointer to the last item instead of page numbers

## Performance Considerations

When implementing pagination, consider:

- Server-side vs. client-side pagination
- Caching strategies
- Preloading next/previous pages
- Maintaining state during navigation

## Accessibility

Pagination controls must be accessible:

- Proper ARIA attributes
- Keyboard navigation
- Clear visual indicators
- Descriptive link text
